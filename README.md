**HotelBook** is a simple web-based platform that allows users to book hotel rooms and receive confirmation messages.

## Features

- User-friendly interface for hotel room booking.
- Immediate confirmation message upon successful booking.
- Lightweight and responsive design.

## Getting Started

1. Download or clone the repository.
2. Navigate to the project directory.
3. Open `HotelBook.html` in your preferred web browser to start using the application.

## Project Structure

- `HotelBook.html` - Main HTML file for the hotel booking application.
- `Website/` - Directory containing website assets and additional resources.
- `Screenshot 1.png`, `Screenshot 2.png` - Images showcasing the application's interface.
